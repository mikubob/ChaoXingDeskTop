# 超星 Windows 桌面版

面向 Windows 的超星课程学习工作台，用一个桌面窗口管理账号、课程、章节任务、题库与 AI 服务，以及逐题结果和日志。

**版本：0.6.6** · **Windows 10 / 11 x64** · **WinUI 3 + Python 后台** · **GPL-3.0**

桌面界面采用原生 **WinUI 3（C# / Windows App SDK）**，提供五页侧栏、账号面板、课程列表、设置分组和任务／日志区。`desktop/run.py` 启动界面，账号、配置、凭据保护和任务协议继续由 Python 后台处理。

开发运行：准备 Python 环境及 .NET 8 SDK，然后在 `desktop` 中运行 `./scripts/build-winui.ps1`、`.venv/Scripts/python.exe run.py`。详见 [WinUI 3 运行与构建](desktop/winui/README.md)。

## 下载与安装

每个已发布版本提供 Windows x64 安装包、该版本的源码 ZIP 和 SHA-256 校验清单。[GitHub 发行历史](https://github.com/mikubob/ChaoXingDeskTop/releases)

下载并运行安装包，按提示完成安装后，从桌面或开始菜单打开「超星桌面版」。首次使用可以直接选择「离线演示」，体验界面和任务流程。

**升级已有版本：** 先退出旧程序，再安装到原目录，即可沿用已有设置、账号和 Cookie。卸载程序会保留个人数据。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 多账号管理 | 添加、切换、备注和删除账号；分别保存加密 Cookie，重启后恢复最后选中的账号 |
| 课程与章节 | 读取与筛选课程，批量选择，配置章节并发、重试与未开放章节处理策略 |
| 媒体进度 | 展示视频 / 音频时长和播放进度，区分本轮处理进度与平台完成确认 |
| 题库与 AI | 配置多个题库的查询顺序、凭据、超时和重试，支持 AI 补全与视觉模型 |
| 答案与逐题结果 | 人工补全、题库答案审核、候选来源与拒绝原因、查询耗时及章节筛选 |
| 任务与日志 | 暂停后续处理、停止任务、日志搜索与级别筛选、脱敏日志持久化 |
| 投票／问卷 | 单选、多选与文本题混合活动；AI / 随机策略、本地草稿、独立提交及逐题记录 |
| 讨论任务 | 四档回复、独立草稿 / 自动提交、本人回复检查、持久化防重复及发布 / 任务点分别核验 |

支持声明式 JSON 题库模板，可配置 GET / POST、题型映射和响应字段路径；模板中的 JavaScript 不会执行。

## 开始使用

1. **连接账号**：在「课程与账号」点击「浏览器登录并读取课程」，在弹出的 Edge / Chrome 完成扫码或网页登录，程序会自动获取 Cookie 并读取课程；也可手动导入 Cookie。
2. **选择课程**：勾选需要处理的课程，在「学习设置」调整倍速、并发和章节策略。
3. **配置服务**：在「题库与 AI」启用所需服务，填写凭据、查询顺序及超时等参数。
4. **启动任务**：点击「开始所选课程」，在「任务与日志」查看章节进度、媒体状态和逐题结果。

题库按顺序查询，AI 补全未解决的题目，启用人工补全后可继续处理剩余答案。随机补全默认关闭。

默认只保存答案。自动提交需要独立开启，并要求所有题目已有答案；仍有空白题目时仅保存。

**讨论任务**：在「题库与 AI → 讨论任务」启用处理，选择精简、中等、详细或固定单字“好”；按需独立开启讨论自动提交。关闭提交时仅保存草稿，在「任务与日志 → 讨论记录」查看和复制。前三档复用 AI 服务；固定好不调用模型。新配置默认关闭讨论处理和提交。

支持经章节 `insertbbs` 明确关联的新版超星讨论；非任务点、未知页面和无法核实本人回复时不自动发布。发布结果未知时保留记录，只读核验，不盲目重发。发布、任务点完成和成绩是三个不同结果。[讨论协议与边界](desktop/vendor/chaoxing/api/DISCUSSION_PROTOCOL.md)

## 窗口与设置

- 在「课程与账号」开启「启动时使用已保存会话登录」，下次启动会读取当前账号的课程。会话失效时可在账号页重新登录。此项默认关闭。
- 配置默认自动保存，可在「高级设置 → 配置保存」关闭。退出时如有未保存配置，可保存并退出、放弃并退出，或返回编辑。
- 点击「最小化到托盘」可收起窗口并继续运行任务。可从 Windows 通知区恢复窗口或退出。

旧版本变更见 [GitHub 发行历史](https://github.com/mikubob/ChaoXingDeskTop/releases)。

## 数据与凭据

账号、Cookie、设置和日志保存在当前 Windows 用户的本地数据目录中。Cookie、题库 Token、AI Key 等凭据使用 Windows DPAPI 加密，通常绑定当前用户与本机；登录密码不写入账号文件。

安装更新保留原配置标识，卸载保留个人数据。**完整 INI 导出包含明文凭据，请留在本机。** 数据位置和迁移规则见 [账号与本机数据](desktop/README.md#账号与本机数据)。

## 常见问题

### 使用安装包还需要安装 Python 吗？

不需要。安装包包含程序及所需运行环境。仅从源码运行或自行构建时需要安装 Python 和依赖。

### 为什么媒体进度达到 100% 后仍显示待核验？

达到媒体时长后，还需要平台确认完成。界面会区分播放进度、本轮章节处理状态和平台确认状态。

### 为什么切换账号后需要重新读取课程？

课程选择与任务结果按当前账号隔离。切换账号会清空当前课程列表和选择，重新读取即可；运行中的任务需要先停止。

### 「暂停后续」会立即暂停所有请求和媒体吗？

它会阻止后续调度、答题请求与写入，在途请求及当前媒体可以继续。需要结束本轮任务时使用「停止」。

## 从源码运行

开发与构建需要 Windows x64、Python 3.13.9 和 .NET 8 SDK。在 PowerShell 中执行：

```powershell
git clone https://github.com/mikubob/ChaoXingDeskTop.git
cd ChaoXingDeskTop/desktop
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
./scripts/build-winui.ps1
.venv/Scripts/python.exe run.py
```

构建环境、安装包生成与发布校验流程见 [开发与构建指南](desktop/README.md#构建与发布)。

```text
desktop/
├── chaoxing_desktop/       # 界面、账号、配置、调度与答案处理
├── vendor/chaoxing/        # 平台协议适配与字体资源
├── scripts/               # 依赖锁定、构建与发布工具
├── assets/                # 应用图标与界面资源

.github/workflows/         # Windows 构建与离线验收
```
